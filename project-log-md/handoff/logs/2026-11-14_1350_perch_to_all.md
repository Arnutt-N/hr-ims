เหตุผลที่ไม่มี service container:
- `requireAuth` อ่าน header เท่านั้น (ไม่ round-trip ไป DB)
- rate limiter ใช้ express-rate-limit in-memory store
- ทั้งสอง suite import `app` ตรง ๆ ผ่าน Supertest ไม่ต้องมี listening server
