## สรุปงานที่ทำ

Dev and production now share one MySQL dialect. `backend/prisma/schema.prisma` uses `provider = "mysql"`. Local development uses MySQL 8 from `docker-compose.yml`. Production stays on TiDB Cloud and is updated with `npm run db:push:prod`, which reads `DATABASE_URL` only. The SQLite-to-TiDB transform scripts are removed. No connection was made to production TiDB.

## ข้อควรระวัง / หมายเหตุ

Iron Rules acknowledged.

`db push` on production can ALTER enum columns and widen some strings to `TEXT` or longer `VARCHAR`. Those alters keep data when every existing value fits the new type. An enum alter fails, and does not delete rows, if a stored value is outside the enum. New indexes are additive. This session did not connect to production.
