### 2.4 timeout 60 วินาที (กลาง)

ตรวจ diff ของ `frontend/next-app/tests/components/login-form.test.tsx` แล้วพบการเปลี่ยนแปลงจริงสองส่วน: (1) ย้าย `vi.resetModules()` ไปหลัง `delete process.env.NEXT_PUBLIC_DEMO_MODE` และเพิ่ม reset ก่อนแต่ละเคสที่ stub env เพื่อกัน stub ค้างข้ามเคส (2) ล้าง cookie `hr-ims-locale` ใน before/after เพราะ jsdom เก็บข้ามเคส แล้วเปลี่ยน assertion เป็น `vi.waitFor` timeout 5000 ms พร้อมตั้ง test timeout 60000 ms สามเคส

คำอธิบายใน handoff ที่ว่าเพิ่ม timeout "สำหรับ dynamic import ภายใต้ fork pool" จึงยังไม่ตรงกับสิ่งที่ diff แสดง: เหตุผลที่เห็นได้ชัดคือการกัน env/cookie leak กับการรอ render แบบ async ไม่ใช่การวัด dynamic import

**สิ่งที่ยังต้องทำตามเกณฑ์ของ Codex:** เก็บเวลารันต่อไฟล์แบบรันเดี่ยวและแบบทั้งชุดภายใต้ fork pool เดียวกับ CI หลายรอบ แยกช่วง dynamic import/โหลดโมดูล/รันเทสต์ แล้วตัดสินใจว่าจะคง 60 วินาทีหรือปรับ ก่อนทำจะไม่เขียนอ้างว่าความช้าอยู่ที่จุดใด

## 3. ลำดับงานที่ยังต้องปิด

อ้างตามตารางของ Codex โดยไม่เปลี่ยนผู้รับผิดชอบที่เสนอ:

0. **ทีมแอปพลิเคชัน** — แยก `.audit/`, `.perch/`, `.claude/skill-collections/`, `.claude/skills/*`, `PRPs/gemini/`, `PRPs/perch/` ออกจากชุดส่งตรวจก่อน `git add` (ดูข้อ 2.1.1) แล้วตัดสินใจว่าจะ ignore หรือ commit แยก
1. **ทีมแอปพลิเคชัน** — ผูกผล unit/authz/Vitest/typecheck กับ snapshot เดียวกัน บันทึกคำสั่ง ตัวแปรสภาพแวดล้อมที่ไม่เปิดเผยค่า เวลา และ exit code ระบุสถานะเกตที่รันไม่จบ ตรวจรายการไฟล์ก่อนเปิด draft PR เมื่อได้รับอนุญาต
2. **เจ้าของระบบกับทีมแอปพลิเคชัน** — รับรองตารางสิทธิ์ดู/อนุมัติ/ปฏิเสธ ตรวจทั้ง Next.js และ Express ด้วยชุดกรณีเดียวกัน ตัดสินใจเรื่องเส้นทางคืนวัสดุ Express (`PATCH /:id/status` ชนิด `return`) ว่าอยู่ในรอบเปิดใช้หรือไม่
3. **ผู้ดูแลฐานข้อมูลกับทีมแอปพลิเคชัน** — รัน migration บน TiDB ทดสอบตาม runbook บันทึกผลรันซ้ำและวิธีกู้คืน ตรวจยอดคงเหลือ/ยอดจอง/ประวัติ/สถานะในกรณีอนุมัติคำขอเดียวกันจากสองช่องทาง คนละคำขอแตะสต็อกเดียวกัน และข้อผิดพลาดกลางรายการ กับยืนยันว่าการปรับยอดรอบเดียวกันมีผลครั้งเดียว
4. **ทีมรายงานกับเจ้าของคลัง** — เทียบยอด SQLite/TiDB ตรงรอยต่อเที่ยงคืนไทย วัด p95 ก่อน/หลังด้วยข้อมูลและภาระงานเดียวกัน รับรองยอดยกมาและแสดงผลทดลองกระทบยอดก่อนใช้บัตรคุม
